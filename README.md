# 🐕 DogeMiner Direct Injector

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![JavaScript](https://img.shields.io/badge/Language-JavaScript-yellow.svg)]()

**DogeMiner Direct Injector** is a lightweight, zero-dependency browser script designed to bypass state locks and give you direct control over DogeMiner. Built with a sleek glassmorphism UI overlay, it executes DOM event synthesis, memory scanning, and UI automation directly from your browser console.

---

## ⚡ Features

* **⚡ Brute-Force Auto-Clicker:** Dispatches native mouse events (`mousedown`, `mouseup`, `click`) to canvas and target selectors on a 15ms loop to maximize clicks per second without triggering rate limits.
* **🔍 Deep Memory Inspector:** Scans active DOM properties, framework state wrappers (`__vue__`, `__reactInternalInstance`), and global `window` objects to locate and mutate currency values.
* **⚡ UI Auto-Buyer:** Automatically scans the screen for visible upgrades and shop items, triggering immediate purchase actions in a single click.
* **⌨️ Hotkey Toggle:** Press **F8** at any time to show or hide the overlay interface without interrupting gameplay or page layout.

---

## 🚀 Quick Start

1. Open **DogeMiner** in your web browser.
2. Open Developer Tools:
   * **Windows/Linux:** Press `F12` or `Ctrl` + `Shift` + `I`
   * **macOS:** Press `Cmd` + `Option` + `I`
3. Click the **Console** tab.
4. Copy and paste the script code, then press **Enter**.
5. Press **F8** to toggle the menu overlay visibility on screen.
